🎮 Tic-Tac-Toe Game
A simple and interactive implementation of the classic Tic-Tac-Toe game, where two players compete on a 3 × 3 grid. The objective is to place three matching symbols in a horizontal, vertical, or diagonal line to win the game.

🔗 GitHub Repository: tic-tac-toe
✨ Features
•	🎯 Interactive Gameplay – Play using a simple game board.
•	👥 Two-Player Mode – Two players take turns making their moves.
•	❌ X and O Symbols – Each player uses a different symbol.
•	🏆 Winner Detection – Automatically identifies the winning player.
•	🤝 Draw Detection – Detects when the board is full without a winner.
•	🔄 Restart Game – Start a new game and play again.
•	🖥️ Simple User Interface – Easy-to-understand gameplay.

🎮 How to Play
1.	Start the Tic-Tac-Toe game.
2.	The game board displays a 3 × 3 grid.
3.	Player 1 uses X, and Player 2 uses O.
4.	Players take turns selecting an empty cell.
5.	The first player to align three symbols horizontally, vertically, or diagonally wins.
6.	If all nine cells are filled without a winning combination, the game ends in a draw.
7.	Restart the game to play another round.
